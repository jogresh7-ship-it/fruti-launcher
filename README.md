# Fruti Launcher

A minimal static game launcher. Open `index.html` in a browser (or host the folder on any static host such as GitHub Pages or Cloudflare).

## Adding games

Edit `games.js`. Each game has a `title`, `tags`, a `url` that opens in the built-in player, and an optional `image` cover. Games without an image get a gradient cover.

## Features

- Featured "Continue Playing" banner that rotates and puts recently played games first
- Recommended row, plus a searchable Library
- Collapsible right sidebar with played history, clock and total play time (saved in the browser)
