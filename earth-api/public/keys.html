🔑 Get a free API key

Use the Earth API on your own website or app: weather, air quality, earthquakes, wildfires, countries, the space station, sunrise and sunset, and more. Free, no sign-up, no email.

1. Create your key

Copy your key now. It's shown only once. We only keep a fingerprint of it, so it can't be recovered. If you lose it, just make a new one.

2. Use it

Add your key to any request as ?key=…, or send it in an x-api-key header. Every response is JSON and works from any website.
