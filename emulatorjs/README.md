# EmulatorJS (bundled)

[EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) 4.2.3 with the `mupen64plus_next` Nintendo 64 core, used by `n64.html`. Licensed under GPL-3.0 (see `LICENSE`).

`embed/` holds base64 copies of the files EmulatorJS downloads at runtime (core, report, decompressors). They are generated by `tools/embed-emulatorjs.py` and are only used when the launcher is opened from disk (`file://`), where browsers block normal downloads.
